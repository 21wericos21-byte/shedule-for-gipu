# Система составления и управления расписанием ГИПУ

Данный проект представляет собой веб-приложение для автоматизации работы деканатов ФГБОУ ВО «Глазовский государственный инженерно-педагогический университет имени В. Г. Короленко» (ГИПУ). 

Система позволяет вносить, редактировать и просматривать расписание занятий с автоматической проверкой конфликтов (коллизий) и последующей выгрузкой данных для интеграции с мини-приложением мессенджера MAX.

## 🚀 Основные возможности

*   **Управление расписанием:** Удобный веб-интерфейс (сетка) для добавления и редактирования пар.
*   **Проверка коллизий:** Автоматический запрет на накладки (одна аудитория, преподаватель или группа не могут быть заняты в одно и то же время).
*   **Аналитика загрузки:** Просмотр текущей занятости аудиторий и преподавателей.
*   **Экспорт данных:** Формирование выгрузки в формате JSON для последующей передачи во внешние сервисы (чат-бот MAX).
*   **Цветовое кодирование:** Возможность выделять разные дисциплины или типы занятий цветом.

## 🛠️ Технологический стек

*   **Язык программирования:** Python 3 (фреймворк Flask).
*   **База данных:** MySQL (управление через phpMyAdmin в составе OSPanel).
*   **ORM:** SQLAlchemy (Flask-SQLAlchemy).
*   **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5.
*   **Интеграция:** REST API, формат обмена данными — JSON.
